# Step 05: 訊息時間戳

## 做了什麼
在 readPump 組訊息時加上時間戳，格式：`[15:04:05] 名字: 訊息`

## 學到的概念

### Go 的 time format 用「magic date」
Go 不用 `yyyy-MM-dd HH:mm:ss` 這種 pattern，而是用固定參考時間：
```
2006-01-02 15:04:05
```
每個數字有意義：01=月, 02=日, 15=時(24h), 04=分, 05=秒。
寫錯數字（例如 `2026`）會被當作字面文字。

### 時間戳加在 readPump 而不是 Hub
訊息在 readPump 裡組裝成最終格式再送進 Broadcast。
Hub 只負責轉發，不修改訊息內容，職責更清晰。
